Undergraduate project · Huazhong Agricultural University · Sep 2022 – Jan 2024

Dynamic Pig-Carcass Weighing System

An STM32 and HX711 load-cell system that weighs pig carcasses while they move along a processing line. The project software is registered as Software Copyright No. 2024SR0141888 (copyright holder: Huazhong Agricultural University).

My role: I wrote the STM32 firmware in C, integrated the HX711 load-cell acquisition and built the serial/Bluetooth link to a host PC, and supported the dynamic-weighing algorithm work.

What I did

  • Developed embedded firmware in C for the STM32-based weighing system.
  • Integrated HX711 load-cell acquisition for real-time weight capture.
  • Supported dynamic-weighing algorithm development to improve signal stability under field-like conditions.
  • Implemented serial and Bluetooth data transfer to a host PC for logging and monitoring.
