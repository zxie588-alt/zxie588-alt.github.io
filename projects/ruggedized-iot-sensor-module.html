Why This Project Exists

This project complements the NZ ventilation case study. The ventilation project targets HVAC, building services and commissioning. This project targets product engineering: enclosure design, DFM, test fixtures, electronics packaging, firmware boundaries and reliability validation.

  • SolidWorks CAD V2 includes detailed lower enclosure, upper lid, gasket, PCB placeholder, battery placeholder and exploded assembly.
  • The model now makes the sealing path, fastening path, strap-mount path and service-access path visible.
  • Proteus will be used for electronics architecture, not a final PCB release.
  • Keil / embedded C will show firmware state-machine thinking once the MCU target is fixed.
  • Abaqus will be used for focused strap-mount and corner-load FEA after geometry exists.

Evidence Boundary

This page currently shows planning documents and SolidWorks concept CAD V1/V2. It does not claim an IP rating, physical test data, production readiness, final PCB design or validated firmware. Those evidence items will be added only after the corresponding work is completed.

CAD V2 Deliverables

SolidWorks Model Set

  • Lower enclosure with screw boss rings, PCB standoff rings, gasket groove intent, internal ribs and battery restraint clips.
  • Upper lid with counterbored screw-pad intent, membrane clamp ring, gasket compression ribs and label recess.
  • Rear strap-mount lugs, side service/debug port boss and front cable-gland ring.
  • More detailed PCB and battery envelopes for package checking.
  • Detailed exploded assembly plus native SolidWorks, STEP and STL outputs.

  • Requirements matrix covering enclosure, sealing, mounting, electronics, firmware and validation.
