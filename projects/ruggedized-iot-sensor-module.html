Why This Project Exists

This project complements the NZ ventilation case study. The ventilation project targets HVAC, building services and commissioning. This project targets product engineering: enclosure design, DFM, test fixtures, electronics packaging, firmware boundaries and reliability validation.

  • SolidWorks CAD V2 includes detailed lower enclosure, upper lid, gasket, PCB placeholder, battery placeholder and exploded assembly.
  • The model now makes the sealing path, fastening path, strap-mount path and service-access path visible.
  • Electronics work is presented as a documented design package with BOM, net ownership, power budget and firmware ownership notes.
  • Keil / embedded C now includes a state machine, pin map, startup file, scatter file and clean uVision ARMCM3 target build.
  • Abaqus is used for completed strap-mount pull, enclosure corner-load and screw-boss compression screening load cases.
  • Thermal exposure simulation identifies sealed-enclosure overheating risk and design actions before prototype testing.

Abaqus Strap-Mount FEA

A screening Abaqus 2025 load case was added for the rear strap-mount lugs. The simplified model applies a 150 N total strap pull, split across the two lug holes, using an assumed PC-ABS material and C3D10 solid mesh.

150 NTotal strap pull load
1.57 MPaMaximum von Mises stress
0.010 mmMaximum displacement
25.47Screening yield ratio

This is early screening FEA: the geometry, support boundary and material values are simplified. It is useful design evidence for load-path thinking, not a certified safety factor or physical validation result.

Abaqus Corner-Load FEA

A second Abaqus 2025 load case screens early drop/handling risk. The simplified enclosure plate surrogate applies a 120 N equivalent static load to one outer corner, with four screw-line support patches representing the fastening load path.

120 NEquivalent static corner load
5.55 MPaMaximum von Mises stress
0.021 mmMaximum displacement
7.21Screening yield ratio

This result documents how the design would be screened before a physical drop test. It is not a dynamic impact certification, but it shows the load-case definition, boundary-condition thinking and evidence control.

Abaqus Screw-Boss Compression FEA

A third Abaqus 2025 load case screens assembly risk at the screw boss. The model uses an axisymmetric local plate and boss section, applying a 90 N equivalent screw clamp load to the top annular contact edge.

90 NEquivalent screw clamp load
1.20 MPaMaximum von Mises stress
0.005 mmMaximum displacement
33.36Screening yield ratio

This is a design-screening result for boss compression and cracking risk. It does not model detailed threads, torque scatter, creep, inserts or a physical pull-out test.

Electronics + Firmware Architecture

The project links the mechanical enclosure to a Keil/uVision firmware project, STM32L4 low-power device-pack audit and PCB design package and candidate MCU porting plan. The current evidence covers component candidates, connection-level net ownership, power-budget assumptions, state-machine behaviour, battery/sensor fault handling and the sealed service/debug interface.

Firmware Evidence

  • Keil/uVision ARMCM3 prototype target build verified through the local uVision command-line launcher.
  • Clean ARM Compiler 6 / ARMCLANG build result: 0 errors, 0 warnings.
  • Program size from the verified target build: Code 500 bytes, RO-data 80 bytes, RW-data 0 bytes, ZI-data 1024 bytes.

  • Candidate STM32L432 pin allocation and porting plan separate the current prototype build from the future board-specific target.

  • Pin map and firmware architecture note covering sleep, sampling, filtering, transmit, low-battery, fault and service states.

Thermal Exposure Simulation

A lumped thermal RC model was added to screen sealed-enclosure temperature risk before physical hardware exists. The model combines a warm ambient ramp, external solar/lamp heat input and electronics duty-cycle pulses from the firmware transmit boundary.

240 minSimulated exposure window
66.6 CPeak internal temperature
55 CWarning reference
RiskDirect exposure needs mitigation

The result is intentionally treated as a risk flag, not a pass claim. Suggested actions include lighter enclosure colour, shaded mounting, reduced radio/LED duty cycle, vent membrane review and future internal/external temperature logging.
