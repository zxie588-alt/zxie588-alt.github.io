Engineering Capability Shown

  • Converted aerodynamic, cornering and bump scenarios into Abaqus load cases for a composite front-wing structure.
  • Built an S4R shell-element laminate model with local refinement around attachment regions where stress concentration mattered.
  • Checked ply-level stresses against fatigue and ultimate allowables rather than only reading global displacement contours.
  • Iterated from an over-designed layup to a lighter quasi-isotropic laminate while retaining strength and stiffness margin.

Key Evidence

The final model used 54,998 shell elements. The governing load case reached about 74% peak stress utilisation with SF = 1.5, and the final main-element mass estimate was about 1.17 kg.

Verification & Limits

Checks Used

  • Used a shell model with local mesh refinement around attachment regions where load transfer and stress concentration mattered most.
  • Compared displacement and stress patterns across aerodynamic, cornering and bump scenarios instead of relying on one contour plot.
  • Reported ply-level utilisation against fatigue and ultimate allowables, with the governing result kept below the chosen design margin.
  • Kept mass estimate visible so the iteration reads as a strength-to-weight trade, not only a pass/fail stress check.

Current Boundary

This is a simulation and laminate-judgement project. It does not include coupon testing, adhesive/joint testing, aerodynamic tunnel data or track validation. The next useful upgrade would be a documented mesh-convergence table and physical coupon comparison for the selected laminate.
